**Avgar Line Tracker** — это десктопное приложение для автоматического отслеживания рейсов в Euro Truck Simulator 2 и American Truck Simulator. Оно читает данные телеметрии игры и отправляет информацию о завершённых рейсах на сервер. Приложение предназначено **исключительно для сотрудников компании AVG** — сервер проверяет принадлежность пользователя к компании по уникальному идентификатору (UUID).

## ✨ Возможности
- 📊 Автоматическое распознавание начала и завершения рейса
- 💾 Сохранение рейсов локально и отправка на сервер
- 🎨 Современный тёмный интерфейс в стиле 2026
- 🔔 Оверлейные уведомления прямо в игре
- 🔄 Автоматическое обновление через GitHub Releases
- 🔑 Автоматическая генерация и привязка UUID при первом запуске — никаких дополнительных действий не требуется

## 📥 Установка
Скачайте последнюю версию установщика со [страницы релизов](https://github.com/AlexVin-Dev/AvglTracker/releases) (файл `Avgar-Line-Tracker-Setup-*.exe`). Запустите его и следуйте инструкциям.

## 🚀 Использование
1. Запустите игру (ETS2 или ATS) с включённой поддержкой телеметрии.
   > Как включить телеметрию — см. [документацию](https://aspirez.ru/docs/). Обычно достаточно установить плагин `trucksim-telemetry` и разрешить чтение данных в настройках игры.
2. Откройте приложение Avgar Line Tracker.
3. При первом запуске приложение автоматически сгенерирует UUID — ваш личный идентификатор в системе AVG. Он сохраняется локально и используется для всех последующих сеансов.
4. Нажмите «Старт» — приложение начнёт отслеживать рейсы.
5. При взятии и сдаче рейса вы увидите уведомление прямо поверх игры.

> **Важно:** Приложение работает только для сотрудников компании AVG, так как сервер телеметрии проверяет принадлежность UUID к компании. Если вы не являетесь сотрудником AVG, ваши рейсы не будут приняты сервером.

## ❓ Часто задаваемые вопросы (FAQ)

**Приложение не видит игру. Что делать?**
Убедитесь, что игра запущена, поддержка телеметрии включена, а плагин `trucksim-telemetry` установлен корректно. Подробная инструкция — в [документации](https://aspirez.ru/docs/).

**UUID не сгенерировался. Куда он сохраняется?**
UUID создаётся автоматически при первом запуске и хранится локально (в каталоге данных приложения, через `electron-store`). Если возникла ошибка — удалите папку с настройками приложения и запустите его снова.

**Сервер отклоняет мои рейсы. Почему?**
Сервер принимает рейсы только от сотрудников AVG. Если ваш UUID не привязан к компании — рейсы будут отклонены. Обратитесь к администрации AVG для привязки.

**Можно ли использовать приложение без членства в AVG?**
Технически — да, но рейсы не будут приняты сервером. Приложение предназначено исключительно для внутреннего использования сотрудниками AVG.

**Где хранятся мои локальные данные?**
В каталоге данных приложения (`%APPDATA%/Avgar-Line-Tracker` на Windows). Там же лежит файл с UUID и накопленной статистикой.

## 🩺 Устранение неполадок

| Проблема | Возможное решение |
|---|---|
| Игра не обнаружена | Проверьте, что ETS2/ATS запущены, телеметрия включена, плагин установлен |
| Нет уведомлений в игре | Убедитесь, что оверлей разрешён в настройках игры и антивируса |
| Рейс не отправляется на сервер | Проверьте интернет-соединение и статус UUID в личном кабинете AVG |
| Приложение не запускается | Переустановите последнюю версию с [releases](https://github.com/AlexVin-Dev/AvglTracker/releases) |
| Ошибка обновления | Скачайте установщик вручную со страницы релизов |

Если проблема не решена — обратитесь в поддержку (см. ниже).
