# Aspirez Route Tracker — телеметрия для ETS2/ATS

[![License](https://img.shields.io/badge/license-BUSL-orange)](./LICENSE)

**Aspirez Route Tracker** — десктопное приложение для автоматического отслеживания рейсов в Euro Truck Simulator 2 и American Truck Simulator. Читает телеметрию игры и отправляет данные о завершённых рейсах на сервер Aspirez.

- 🏠 Сайт: [aspirez.ru](https://aspirez.ru)
- 📚 Документация: [aspirez.ru/docs](https://aspirez.ru/docs/)
- 🐞 Баг-трекер: [gitverse.ru/.../tasktracker](https://gitverse.ru/AlexVin-Dev/AvglTracker/tasktracker?view=list)
- 📦 Релизы: [gitverse.ru/.../releases](https://gitverse.ru/AlexVin-Dev/AvglTracker/releases)

## ✨ Возможности
- 📊 Автоматическое распознавание начала и завершения рейса
- 💾 Локальное сохранение рейсов и отправка на сервер
- 🎨 Тёмный интерфейс в стиле 2026
- 🔔 Оверлейные уведомления прямо в игре
- 🔄 Автоматическое обновление (generic-провайдер `cdn.velfan.ru`)
- 🔑 Автоматическая генерация UUID при первом запуске
- 🖥️ Определение активного окна игры (`active-win`, `ps-list`)
- 🎮 Интеграция с медиа-сессиями Windows (`win-media-control`, `windows-media-sessions`)
- ⌨️ Управление вводом через `@nut-tree-fork/nut-js`

## 📥 Установка
1. Скачайте последний установщик со [страницы релизов](https://gitverse.ru/AlexVin-Dev/AvglTracker/releases) — файл вида `Aspirez-Route-Tracker-Setup-3.3.0.exe`.
2. Запустите его и следуйте инструкциям мастера (NSIS, установка per-user, можно изменить каталог).
3. После установки создаются ярлыки на рабочем столе и в меню «Пуск».

Поддерживается только **Windows** (target: `nsis`).

## 🚀 Использование
1. Запустите игру (ETS2 или ATS) с включённой поддержкой телеметрии.
   > Как включить телеметрию — см. [документацию](https://aspirez.ru/docs/).
2. Откройте Aspirez Route Tracker.
3. При первом запуске автоматически генерируется UUID и сохраняется локально (`electron-store`). Никаких ручных действий не требуется.
4. Нажмите «Старт» — приложение начнёт отслеживать рейсы.
5. При взятии и сдаче рейса появится оверлейное уведомление поверх игры.

## ❓ FAQ

**Приложение не видит игру.**
Убедитесь, что игра запущена, телеметрия включена, плагин `trucksim-telemetry` установлен. Инструкция — в [документации](https://aspirez.ru/docs/).

**UUID не сгенерировался.**
UUID создаётся при первом запуске и хранится в каталоге данных приложения (`electron-store`). При ошибке — удалите каталог настроек и запустите приложение снова.

**Сервер отклоняет рейсы.**
Проверьте, что UUID привязан к аккаунту и интернет-соединение активно. Если проблема сохраняется — обратитесь в поддержку.

**Где хранятся локальные данные?**
В каталоге данных приложения (на Windows — `%APPDATA%/Aspirez-Route-Tracker`): там файл с UUID и накопленная статистика.

## 🩺 Устранение неполадок

| Проблема | Решение |
|---|---|
| Игра не обнаружена | Проверьте, что ETS2/ATS запущены, телеметрия включена, плагин установлен |
| Нет оверлейных уведомлений | Разрешите оверлей в настройках игры и антивируса |
| Рейс не отправляется на сервер | Проверьте интернет и статус UUID в личном кабинете |
| Приложение не запускается | Переустановите последнюю версию с [релизов](https://gitverse.ru/AlexVin-Dev/AvglTracker/releases) |
| Не работает автообновление | Обновитесь вручную с релизов; см. примечание ниже |

## ⚙️ Автоматическое обновление
Обновления публикуются через **generic-провайдер** `electron-updater` на CDN `cdn.velfan.ru:22007/telemetry/`. Приложение само проверяет наличие новой версии и предлагает установить её.

> ⚠️ **Примечание для сопровождающих:** `build.publish.url` сейчас использует `http://`. `electron-updater` по умолчанию требует HTTPS — для корректной работы автообновления нужен TLS-прокси перед CDN либо флаг `allowInsecureConnections` в настройках updater'а.
